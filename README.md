# Our Space 🚀

> A responsive real-time web dashboard and scheduling application built with a modern glassmorphic UI and powered by Firebase Realtime Database.

---

## 🌟 Features

* **Real-Time Synchronization:** Seamlessly sync tasks, schedules, and dashboard updates across clients instantly using Firebase Realtime Database.
* **Interactive Scheduling Dashboard:** Organize daily routines, appointments, and shared team milestones in one centralized view.
* **Modern Glassmorphic UI:** Designed with custom color palettes, soft frosted-glass effects, gradients, and subtle drop shadows for an immersive user experience.
* **Fully Responsive Design:** Optimized layouts that adapt fluidly across desktop workstations, tablets, and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Properties & Glassmorphism), JavaScript (ES6+)
* **Database & Backend:** Firebase Realtime Database
* **Version Control:** Git & GitHub
